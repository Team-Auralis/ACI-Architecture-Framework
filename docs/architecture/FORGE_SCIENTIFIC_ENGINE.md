# FORGE Scientific Discovery Engine

FORGE operates a continuous scientific reasoning loop. Initial implementations will be entirely simulated. Autonomous scientific discovery will not be claimed until demonstrated.

## Target Architecture Loop
1. OBSERVE
2. QUESTION
3. HYPOTHESIS
4. SIMULATE
5. EXPERIMENT DESIGN
6. HUMAN / AUTHORIZED EXECUTION
7. RESULTS
8. ANALYSIS
9. VERIFICATION
10. KNOWLEDGE UPDATE
11. NEW HYPOTHESIS

## Benchmark Tasks
- Hypothesis generation
- Experiment design
- Simulation execution
- Result interpretation
- Competing hypotheses
- Evidence evaluation

*Note: Every scientific claim must have exact provenance tracing back to the raw data and the agent that generated the hypothesis.*
