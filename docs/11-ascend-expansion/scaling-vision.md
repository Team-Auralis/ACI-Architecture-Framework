# Scaling Vision

ORION does not scale by buying a bigger server. It scales horizontally across organizations.

## The Decentralized Future
If a system relies on a single central database, it has a mathematical ceiling. Eventually, the locking mechanisms will choke, or the database will become too large to failover quickly.

ORION scales by fracturing. Instead of one massive network, there will be thousands of independent, self-sustaining ORION meshes (e.g., one for the State of California, one for a private logistics company). The scaling vision focuses on how to effortlessly bridge these independent meshes together during a crisis, rather than forcing them into a single monolith.
