# Simulation Dynamics

Simulations in ORION run in accelerated time.

## Accelerated Playback
During a slow-moving disaster (e.g., a massive wildfire or rising floodwaters), time is the critical variable. 
MIRROR can ingest current wind speeds and topography, and run a 72-hour simulation in 5 minutes. 
This allows Command to review 5 different evacuation strategies, see the simulated outcome of each (e.g., Strategy A results in traffic gridlock, Strategy B clears the zone in time), and then deploy the winning strategy to the physical world.
