# The Digital Twin

In ORION, a Digital Twin is not a 3D video game. It is a live, mathematical graph database.

## Live Synchronization
The Twin is entirely data-driven. It subscribes to the OMNIS telemetry feed.
*   If a LoRaWAN sensor detects rising water levels, the virtual river in the Twin rises.
*   If a Responder Vehicle moves coordinates, its virtual avatar moves.
*   If an Edge Node loses its satellite uplink, the virtual node goes dark.

This allows Command Operators to look at the Next.js Dashboard and toggle between "Live Reality" and "Simulated Future."
