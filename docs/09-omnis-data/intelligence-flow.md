# The Intelligence Flow

Data is useless; Intelligence is actionable.

The lifecycle of an ORION data point:
1.  **Raw Telemetry:** A sensor detects a vibration (Data).
2.  **Ingestion & Normalization:** Leaf node converts it to a CloudEvent JSON.
3.  **Aggregation:** Edge node compares it against the last 5 minutes of vibrations (Information).
4.  **AI Analysis (SENTIENCE):** The Anomaly Agent correlates the vibration with an incoming SOS from the same area (Intelligence).
5.  **Actionable Output:** The Dashboard highlights the bridge in red and recommends re-routing all ambulances (Action).
